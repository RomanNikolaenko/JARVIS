Plugins

Plugins are MCP servers that JARVIS starts on this computer. Agents can use their tools; every call goes through the security policy and asks you first unless you lower a tool's risk.

A plugin is a program that runs with your user rights: it can read your files and use the network on its own. JARVIS does not sandbox it. Add only plugins you trust.
