# @jarvis/shared-types

TypeScript types for the IPC contract between the Angular UI and the Rust core.

The Rust types are the single source of truth. Bindings are generated by
[ts-rs](https://github.com/Aleph-Alpha/ts-rs) into `src/generated/` by the
`export_typescript_bindings` test in `apps/desktop/src-tauri/src/bindings.rs`,
which lists the root types of the IPC contract. The export location is
configured in `/.cargo/config.toml`.

```bash
cargo test --workspace            # or: cargo test -p jarvis-desktop --lib bindings
```

CI fails if the committed bindings differ from the generated ones. The desktop
app imports them through the `@jarvis/shared-types` TypeScript path alias.
